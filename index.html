I enjoy combining logic and creativity to design systems that are both highly functional and aesthetically pleasing.

1. Remue-méninges physique 1. Physical Brainstorming

J'utilise des supports physiques (tableau blanc, papier) pour réfléchir, esquisser des idées et conceptualiser une solution en prenant du recul. I use physical mediums (whiteboard, paper) to brainstorm, sketch ideas, and conceptualize a solution while stepping back.


2. Raffinement et documentation 2. Refinement and Documentation

Je passe à un document numérique pour peaufiner mon plan, sélectionner la solution idéale, et définir les modèles de conception. I switch to a digital document to refine my plan, select the ideal solution, and define design patterns.


3. Modélisation (Diagrammes) 3. Modeling (Diagrams)

Au besoin, je crée des diagrammes détaillés pour illustrer les interactions au sein du système. If needed, I create detailed diagrams to illustrate the interactions within the system.


4. Implémentation 4. Implementation

Ce n'est qu'une fois l'architecture solidement planifiée que je commence à programmer. I only start programming once the architecture is solidly planned.
